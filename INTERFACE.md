# POC integration contract

Coordinate convention: world Z=0 is surveyed road, meters. Camera world->camera: Xc=Rcw X+tcw. Raw distorted pixels throughout. Body x forward; rear same-side wheel-road contact is body origin; front same-side contact determines heading. Endpoints are the SAME rigid visible physical front/rear longitudinal extreme points in all marked frames, not changing silhouette tangents.

Calibration JSON:
```
{"schema_version":1,"image_size":[960,540],"model":"brown","K":[[700,0,480],[0,700,270],[0,0,1]],"D":[0,0,0,0,0],"Rcw":[[1,0,0],[0,-0.4472135955,-0.894427191],[0,0.894427191,-0.4472135955]],"tcw":[0,0,11.1803398875],"road_polygon":[[-15,-3],[15,-3],[15,8],[-15,8]],"calibration_id":"example-not-real"}
```
model is brown or fisheye (4 D coeffs). Strict video image_size match. Example camera center [0,-10,5]. No real calibration supplied.

Observation file: {"schema_version":1,"video_sha256":"...", "tracks":[{"track_id":"vehicle-1","observations":[{"frame":0,"rear_contact_uv":[u,v],"front_contact_uv":[u,v],"rear_uv":[u,v],"front_uv":[u,v]}]}]}. One frame can contain multiple tracks. All four points required; optional "sigma_px":1.0 (default 1). User annotations identify vehicles and override diagnostic foreground detection IDs. Original pixels, frame is zero-based. Annotation sidecar MUST match video hash. Full-vehicle ground truth is separate CSV track_id,vehicle_id,length_m; vehicle_id identifies physical vehicle across repeat runs (optional defaults to track_id). Never input truth into measurement.

Geometry module supplied by parent: from vehicle_metrology.geometry import Camera, measure_track
Camera.from_dict(calibration_dict); camera.to_dict(); camera.project(world_points Nx3) returns Nx2; camera.ground(pixels Nx2) returns Nx3; camera.image_size (width,height).
measure_track(camera, observations, min_frames=4, pixel_sigma=1.0, mc_samples=0, seed=0) -> JSON-serializable dict with track status, length_m (null if rejected), reasons list, diagnostics dict and frames list. diagnostics includes reprojection_rmse_px, ray_angle_deg, condition_number, endpoint_world_body, uncertainty interpretation where available. frames contains frame, x_m,y_m,heading_deg and local/prefix diagnostics as available. Invalid inputs raise ValueError; geometrically unobservable measurement returns rejection. Do not swallow programming errors.

Runner should process actual local video frame by frame, default display with pause/step and R replay; --headless disables display; optional --output-video path; --output-dir default runs/<video stem>; --calibration JSON optional (no metric output without it); --observations JSON optional; --ground-truth CSV optional; --seed; --mc-samples. No automatic downloading or live streams. Diagnostic MOG2 foreground detection + deterministic box association when no annotations: explicitly not semantic vehicle classification; report null meter estimates. Overlay all annotated contacts/endpoints, per-track estimates and status; display final offline multi-frame estimate as 'whole-track' not per-frame instantaneous measurement. Save JSON results, frame JSON/CSV diagnostics and ground-truth metrics. Hash video/calibration/observations and record versions/config. Repeat same seed/environment gives same core result; runtime/performance timestamps excluded from comparisons. Results must never emit NaN/Infinity (JSON allow_nan=False).

Test runner is scripts/run_tests.sh (new standalone project, not Hermes repo). It runs .venv/Scripts/python.exe -m pytest or .venv/bin/python -m pytest. No commits or git init requested. Dependencies: numpy>=1.26,<3 scipy>=1.11,<2 opencv-python>=4.8,<5 pytest>=8,<9. Parent owns geometry.py, calibration.py, calibrate.py, synthetic generator, README/DESIGN, dependency files. Runner implementer owns test.py, vehicle_metrology/video.py, vehicle_metrology/evaluation.py, annotate.py and tests/test_video.py/tests/test_evaluation.py, and may create tests/conftest.py if needed. Do not edit parent files.
