# Применение детектора и редактор калибровки — 29 сентября 2026

Выбор детектора в редакторе раньше менял только черновик. Применение требовало открытого кадра, а IP API возвращал 409 при работающих камерах. Кроме того, независимые стартовые запросы профиля для видео могли перезаписать более новый выбор браузера.

Теперь оператор выбирает модель в «Изменить детектор» и нажимает «Применить модель». IP API меняет только модель и размер входа в актуальном профиле под общей блокировкой. Разметка, эталоны, коррекция, параметры синхронизации и автоматическое измерение сохраняются. Для работающего источника новые веса проходят пробное обнаружение до остановки старого. При ошибке загрузки старый поток и файл настроек не меняются. Если запуск замены завершился ошибкой, API восстанавливает прежний профиль и соединения. Состояние сервера и сохранённый JSON содержат выбранную модель. Потоки изображений переподключаются по новому идентификатору сессии.

Калибровка оформлена в светлом стиле станции и переведена на русский. Сохранённый профиль загружается автоматически; модель можно менять без кадра. Вверху находятся источник, состояние черновика, модель на сервере и единая кнопка применения. Сохранены коррекция объектива, полигон, мерные линии, эталоны, линия измерения, ручная рамка, проверка кадра, видео, отправка в очередь и импорт/экспорт JSON. Добавлены отмена правок, увеличение кадра до 300%, числовой ввод длины, доступ к режиму оценки/строгому режиму и допуску. Черновики разных источников не копируют геометрию друг в друга.

Проверки: 236 Python-тестов и 52 frontend-теста. Новые сценарии проверяют переключение работающей станции, сохранение геометрии, откат после ошибки запуска, отказ при недоступных весах, сохранение без кадра/GPU, применение из оператора, перезагрузку настроек, защиту от запоздавшего запроса, независимые черновики, отмену коррекции и увеличение ещё загружаемого кадра.

В браузере проверены: RT-DETR X без открытого кадра → применение → перезагрузка с тем же выбором; смена на RT-DETR L из оператора; встроенная калибровка; открытие исходного ST-кадра с прежней коррекцией и разметкой. Для UI использован изолированный сервер с настоящими API и сохранением JSON, но тестовыми приёмниками и проверкой модели. NVIDIA GPU и живые камеры в этой среде недоступны; реальное выполнение новых весов на рабочей видеокарте этим прогоном не подтверждено. Алгоритм длины и заявленный предел его точности не менялись.
