Измеренная длина

Введите длину, проверенную по независимому измерению или точной модели автомобиля. Сохраняйте только полную рамку нужного автомобиля. Если не уверены, нажмите «Пропустить».

Полные кадры и исходная оценка камеры сохраняются для сравнения. Фактические длины входят в JSON как данные оценки и, для подходящих рамок, как эталоны совместимой калибровки. Чтобы использовать новые эталоны в измерении, загрузите JSON в «Калибровка» и нажмите «Сохранить и применить». Пропущенные кадры доступны в отдельной очереди.
