Измеренная длина

Измеряйте полную длину прямого состава, включая прицеп, промежутки и выступающий груз. Для независимой проверки нужны физический замер, его погрешность и постоянный ID автомобиля. Каталог подходит только как подсказка для калибровки. Назначение закрепляется при первом сохранении длины. Если не уверены, нажмите «Пропустить».

Сохраняются полные исправленные кадры и исходная оценка камеры. Все проверенные длины входят в JSON. Автомобили из независимой проверки не используются для подгонки масштаба. Подходящие рамки из выборки калибровки добавляются как эталоны; чтобы применить их, загрузите JSON в «Калибровка» и нажмите «Сохранить и применить». Пропущенные кадры доступны в отдельной очереди.
